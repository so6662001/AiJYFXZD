ERP 内嵌四层技术架构

数据层 → 指标引擎 → 规则判别 → 大模型推理 → 诊断输出

层1数据接入层

自动拉取 ERP 原生业务表，无需额外对接。数据清洗（剔除作废/退货冲红/脏数据）、周期切片（近3/6/12月+同期）、维度聚合。

销售明细表客户档案表销售员档案结算应收表库存表→ 预制指标宽表

层2规则引擎层 · 报表按字节计 Token（低）

SQL 存储过程 + ERP 内置表达式引擎，本地化计算。先靠固定业务规则标记机会点/风险点，过滤正常数据，减少大模型调用。

客户诊断规则库市场诊断规则库员工诊断规则库输出：对象ID+风险标签+机会标签+类型

层3大模型推理层 · 消耗 Token

仅对带风险/机会标签的对象调用大模型；结构化 JSON 指标 + 系统标签 + 钢贸专属 Prompt。支持实时单次调用与凌晨定时批量。三段式输出：数据解读 → 深层归因 → 落地动作。

高盈利客户 → 扩品类高走量客户 → 缩账期区域 → 人力/库存调配员工 → 资源/考核/培训

层4诊断输出与落地层

双层展示：常规报表预警区（规则拼接，按输入/输出字节计 Token）+ AI 智能诊断区（大模型 token 计费，未开通则隐藏）。诊断结果缓存 7 天，重复查看不重复扣 Token。

核心计算模型（Excel/SQL 通用口径）

通用基础口径

  • 单笔毛利 = 金额 − 成本价
  • 单笔业务净利 = 单笔毛利 + 其他收入 − 其他支出
  • 单吨业务净利 = 单笔业务净利 ÷ 重量（重量≠0）
  • 现款判定：结算方式 = 现款现结；赊销：账期 > 0
  • 逾期判定：结算到期日 < 当前日期 且 未结清
  • 全局阈值 X0=客户总重量中位数、Y0=单吨净利中位数（每日自动重算）

客户类型判定模型（走量/盈利）

// X=总采购吨 Y=单吨净利 X0/Y0=全局中位数 =IF(AND(X>=X0,Y>=Y0),"①量利双优", IF(AND(X<X0,Y>=Y0),"②高盈利获利型", IF(AND(X>=X0,Y<Y0),"③高走量流水型", "④量利双弱低效")))

潜力打分权重：总净利 40% · 采购吨数 25% · 复购频次 20% · 资金安全 15%
