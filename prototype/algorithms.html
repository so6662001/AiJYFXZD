指标与算法字典 · 全量计算口径

系统内所有指标与能力分析的具体算法。全部基于现有销售明细字段（销售日期、客户、销售员、重量、金额、成本价、毛利、其他收支、业务净利、账期、结算方式、结算到期日、品类、材质、产地、地区、客户分类/级别等）计算。公式给出 Excel / SQL 通用写法，阈值均可后台配置。

📖
阅读约定：周期指统计窗口（近3/6/12月/当月）；X0=全客户总重量中位数、Y0=全客户单吨净利中位数（每日自动重算）；所有"占比/率"以小数或百分比表示。

通用计算口径（全表通用）

基础单笔口径

// 单笔（每行销售明细） 单笔毛利 = 金额 − 成本价 单笔业务净利 = 单笔毛利 + 其他收入 − 其他支出 单吨业务净利 = 单笔业务净利 ÷ 重量 // 重量≠0 挂价毛利差 = 实际毛利 − 挂牌毛利 // 判定 现款 : 结算方式 = "现款现结" 赊销 : 账期 > 0 逾期 : 结算到期日 < TODAY() 且 未结清货款

全局阈值（自动计算）

X0 = MEDIAN(各客户 周期总采购吨数) // 走量阈值 Y0 = MEDIAN(各客户 平均单吨净利) // 盈利阈值 G_avg = 全局 区域/品类 单吨净利均值 // 市场分级基准 // 加权平均账期(按吨位加权，避免小额干扰) 加权账期 = SUMPRODUCT(单笔账期 × 单笔重量) ÷ 总重量 // 活跃客户 活跃客户 = 周期内下单次数 ≥ 2 的客户（去重计数）

市场维度算法

区域 / 品类 / 下游行业

1.1 区域指标库（按 省/市/区县/片区 分组统计）

类别指标算法
规模总销量(吨)SUMIFS(重量, 区域匹配, 周期)
总营收 / 累计净利SUMIFS(金额 / 业务净利, 区域匹配, 周期)
客户总数 / 活跃客户数去重计数(客户) / 下单≥2次客户数
盈利平均单吨净利区域总业务净利 ÷ 区域总销量
整体净利率区域业务净利 ÷ 区域总营收
挂价毛利差值Σ(实际毛利 − 挂牌毛利)
风险加权平均账期SUMPRODUCT(账期×重量) ÷ 总重量
赊销占比 / 现款占比赊销订单重量 ÷ 总重量 ；现款重量 ÷ 总重量
结构终端客户占比(制造+工程客户数) ÷ 客户总数
各类客户销量占比某客户分类销量 ÷ 区域总销量
趋势销量同比增速(本期销量 − 上期同维度销量) ÷ 上期
净利同比增速(本期净利 − 上期净利) ÷ 上期

1.2 区域市场潜力四象限判定

// 增速阈值 20%，单吨净利与全局均值 G_avg 比较 市场标签 = IF(AND(增速 ≥ 0.20, 单吨净利 ≥ G_avg), "明星市场", IF(AND(增速 ≥ 0.20, 单吨净利 < G_avg), "蓝海潜力市场", IF(AND(增速 > −0.20, 单吨净利 ≥ G_avg), "成熟存量市场", "衰退弱势市场")))

1.3 品类 / 产地 / 计价分析

// 单品盈利潜力（按单吨业务净利排序） 单品单吨净利 = 品类总业务净利 ÷ 品类总重量 品类销量占比 = 品类销量 ÷ 全司总销量 // 产地对标：同规格不同产地 产地净利差 = 产地A单吨净利 − 产地B单吨净利
// 计价方式差异（理计 / 过磅） 计价单吨毛利差 = 理计组单吨毛利 − 过磅组单吨毛利 // 品类需求趋势：月度环比 月环比 = (本月销量 − 上月销量) ÷ 上月销量

1.4 下游行业指标 & 市场预警规则

规则触发条件动作
蓝海市场连续3个月销量同比增长 ≥ 20% 且 单吨净利 ≥ G_avg增配人力、库存倾斜
衰退市场销量同比 ≤ −30% 且 中间商客户占比 > 80%收缩赊销授信、人员缩编
蓝海品类单吨毛利高 且 整体采购规模小（未开发）专项攻坚、投放优惠
风险品类连续2月毛利为负 或 库存积压 > 30天清库调价

行业综合评分雷达（0-10）：销量规模、单吨毛利、购货频次、账期健康、逾期风险(低) 五维标准化打分。

客户维度算法

价值 / 购货频率 / 分层 / 流失

2.1 基础价值指标

类别指标算法
交易规模累计采购金额/重量、年均净利SUMIFS(金额/重量/业务净利, 客户匹配, 周期)
盈利质量平均单吨毛利、净利率总业务净利 ÷ 总重量 ；净利 ÷ 营收
资金健康加权账期、逾期次数、现款占比SUMPRODUCT(账期×重量)/总重量 ；COUNTIFS(逾期) ；现款重量/总重量
合作广度合作品类数量COUNTA(UNIQUE(品类+材质))

2.2 购货频率核心指标（5 项）

// ① 采购频次 下单总次数 = COUNTIFS(客户匹配, 周期内销售日期) // 按日期去重 月均购货次数 = 下单总次数 ÷ 周期月数 // ② 采购周期 / 平均采购间隔天数（购货频率核心） Step1: 取该客户周期内全部销售日期，去重、升序 D=[d1..dn] Step2: N = 去重日期数 Step3: IF N≤1 → AvgT = 999（一次性/沉睡） ELSE 间隔数组 T=[d2−d1, d3−d2, ... dn−d(n−1)] AvgT = AVERAGE(T) // 平均间隔 MaxT = MAX(T) // 最大断档 RecentT= AVERAGE(近3次间隔) // 近期节奏 // ③ 采购稳定性（变异系数，越小越稳定） CV = STDEV(各月采购金额) ÷ AVERAGE(各月采购金额) // ④ 采购增量（近6个月同比） 增量 = (近6月采购 − 上一个6月采购) ÷ 上一个6月采购 // ⑤ 采购广度 广度 = 合作品类/材质规格 去重数量

2.3 购货频率分层标准

层级判定（平均间隔 AvgT）说明跟进要求
高频稳定AvgT ≤ 30 天（月均≥2次）核心优质客户半月回访一次
中频间歇30 < AvgT ≤ 90 天重点激活月度常规回访
低频疲软90 < AvgT ≤ 180 天低频预警重点跟进缩短周期
沉睡AvgT > 180 天 或 = 999沉睡/一次性一周内电话激活

2.4 客户类型判定（走量 / 盈利双维矩阵）

// X=总采购吨(I)，Y=单吨净利(L)；X0/Y0=全局中位数 客户类型 = IF(AND(X ≥ X0, Y ≥ Y0), "①量利双优", // 高吨+高利，核心头部 IF(AND(X < X0, Y ≥ Y0), "②高盈利获利型", // 低吨高利，利润支柱 IF(AND(X ≥ X0, Y < Y0), "③高走量流水型", // 高吨低利，现金流 "④量利双弱低效"))) // 低吨低利，待清理

2.5 客户综合潜力打分（总分 10 分，四维加权）

// 每项 0-10 标准化（在全客户中分位标准化） 利润得分 (40%) : 总业务净利分位标准化 → 0~10 规模得分 (25%) : 总采购吨数分位标准化 → 0~10 复购得分 (20%) : 采购间隔越短越高，AvgT≤30天满分10 资金得分 (15%) : 账期短、无逾期高分 综合潜力分 = 利润×0.40 + 规模×0.25 + 复购×0.20 + 资金×0.15
8~10 一级重点深挖 6~7.9 二级稳定维护 4~5.9 三级常规维护 <4 休眠待清理

2.6 客户流失风险评分模型（4 因子加权，纯算法·可配置）

// 各因子 0-100 分 S1 断单时长(40%) : ≤30→0 · 30-90→30 · 90-180→70 · >180→100 S2 采购下滑(30%) : ≤0→0 · ≤30%→40 · ≤60%→70 · >60%→100 // 下滑率=近3月vs上3月降幅 S3 节奏恶化(20%) : RecentT/AvgT ≤1→0 · ≤1.3→30 · ≤1.8→60 · >1.8→100 S4 资金恶化(10%) : 存在逾期 或 现款转赊销 或 账期拉长≥30天 → 100，否则 0 流失总分 = S1×0.4 + S2×0.3 + S3×0.2 + S4×0.1 分级: 0-25 低 · 26-50 潜在 · 51-75 高 · 76-100 极高 // 附加硬预警标签（不参与打分，强制提示） 量利双优/高盈利客户 进入高风险 → 核心利润客户流失预警 高走量客户 断单 > 60天 → 现金流客户流失预警 连续2月业务净利为负 → 亏损客户流失预警

※ 权重与各档阈值均在「购货频率·流失预警」页面可视化配置，实时重算。

2.7 采购趋势 & 跟进优先级

// 近3月采购同比 同比 = IF(同期=0, "新增客户", (本期−同期)÷同期) // 流失预警硬规则 连续2月无下单 或 采购量环比 ↓≥50% → 流失预警
// 跟进优先级（按客户类型映射） ①量利双优 → 一级（每周线下拜访+月度复盘） ②高盈利 → 一级（专属报价、高层对接） ③高走量 → 二级（半月沟通、优化账期） ④量利双弱 → 三级（月度线上回访）
